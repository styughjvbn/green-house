# 기능 요약

## 1. 대시보드

농장 운영 상태를 빠르게 확인하는 진입 화면이다.

표시 대상:

- 전체 동/배드/구역 수
- 전체 난 묶음 수
- 상태 이상 수
- 분갈이 예정 수
- 최근 작업
- 판매/입금 요약
- 빠른 이동 링크

대시보드는 상세 수정 화면이 아니다.

## 2. 농장 현황

전체 농장을 조회하는 화면이다.

핵심 역할:

```text
전체 농장의 난 묶음 위치·빈 구간·상태 분포 확인
→ 정규화 배치에서 동별 점유 현황 비교
→ 실제 배치에서 현장 위치 관계 확인
→ 동·물리 다이·논리 구역·난 묶음 선택
→ 오버레이 패널에서 선택 범위와 상세 확인
```

기본 보기는 모든 동을 같은 크기로 비교하는 정규화 배치다. 실제 크기가
아닌 비교용 배치임을 화면에 표시하며, 실제 배치는 현장 위치 관계 확인을
위한 보조 보기로 제공한다.

난 묶음 위치 블록은 전체 농장 수준부터 표시한다. 확대 단계가
`농장 / 동 / 다이 / 구역`으로 바뀔 때 라벨 정보량만 늘리며, 낮은 단계에서는
상태·선택·검색 결과·빈 구간을 우선 표시한다. 채움색 기준은 상태·품종·년생
중 선택하고, 상태 테두리와 선택·검색 강조는 별도로 유지한다.

검색·보기 설정·범례·줌은 지도 위 오버레이로 제공한다. 상세 패널도 지도
오버레이로 열며 선택 위치가 패널 뒤에 가려지지 않도록 지도 중심을 보정한다.

농장 현황은 조회와 위치 파악에 집중한다.

하지 않는 작업:

- 난 묶음 생성
- 난 묶음 보정
- 난 묶음 삭제
- 드래그 이동

수정이 필요하면 난 묶음 관리 화면으로 이동한다.

## 3. 난 묶음 관리

난 묶음을 실제로 생성, 수정, 삭제, 이동하는 작업 화면이다.

주요 기능:

- 전체 농장의 물리 다이를 동 번호와 다이 표시 순서 기준으로 연속 탐색
- 이전·다음 동 이동, 동의 첫 다이 빠른 이동
- 한 화면에 물리 다이 2~4개 표시 및 다이 단위 스와이프
- 현재 표시 다이와 앞뒤 이동 버퍼만 부분 조회하고 방문한 범위는 캐시에서 재사용
- URL의 `startBedId`, `bedCount`로 현재 위치와 표시 개수 복원
- 배드별 좌/우 논리 구역 표시
- 난 묶음 등록/보정/삭제
- 난 묶음 보정 중 지도에서 모든 논리 구역을 선택해 배치 위치 변경
- 선택한 난 묶음 정보 기반 복사 등록
- 품종별 난 묶음 색상 구분 토글
- 현재 표시 다이 범위의 난 묶음 목록과 작업 요약
- 검색어가 없을 때 현재 표시 범위 목록 유지
- 검색어 입력 시 현재 목록 또는 전체 농장 범위를 선택해 결과만 조회
- 검색어와 관련된 자동 그룹·사용자 그룹을 함께 제안하고 선택한 그룹의 구성원 목록 조회
- 화면·전체·그룹 검색 범위는 배타적으로 선택하며 그룹 선택 시 해당 구성원만 맵에서 활성화
- 다이 이동 후에도 선택 난 묶음 유지 및 화면 밖 상태 안내
- 다중 선택 모드에서 목록과 지도 난 묶음을 함께 선택하고 선택 개수·총 수량·대상 목록 확인
- 다중 선택한 난 묶음은 공통값으로 일괄 보정하고, 서로 다른 필드는 난 묶음별 기존 값을 유지할 수 있다. 경고 재확인 후 대상별 변경 전후 값을 최종 확인하고 한 번에 저장한다.
- 묶음 관리에서 단일 또는 다중 선택 후 작업 추가를 누르면 작업 관리의 작업 등록 모달을 열고, 선택한 난 묶음을 변경할 수 없는 직접 선택 대상으로 지정한다.
- 난 묶음 등록/보정은 품종 마스터에서 검색 선택한 품종 기준으로만 처리한다.
- 다른 동 이동 목적지 선택
- 화분 크기는 표준 규격 선택값만 신규 저장
- 이동 후 자리 이동 이력 자동 생성
- 배드 정밀 설정/자리 차지 정보 확인
- 선택 난 묶음의 사용자 그룹 생성·추가·해제
- 사용자 그룹별 묶음 수와 총 수량 확인, 사용 종료 그룹 보관
- 현재 표시 범위의 난 묶음을 품종·현재 년생·화분 크기로 자동 그룹화
- 자동 그룹의 묶음 수·총수량·위치 수 확인과 구성원 일괄 선택
- 난 묶음 목록 체크박스 다중 선택 후 사용자 그룹 일괄 추가·해제

## 4. 작업 이력

농약, 비료, 분갈이, 정리, 상태 기록, 메모, 자리 이동을 기록한다.
상세 대상·상태·전파 정책은
[`features/work-operation-and-orchid-collection.md`](features/work-operation-and-orchid-collection.md)를 따른다.

주요 기능:

- 작업 이력 등록
- 대상 유형 선택
- 기간/대상/작업 유형 필터
- 작업 유형 추가/수정/비활성화/정렬
- 자리 이동 이력 자동 생성
- 입고 기록처럼 작업별 필드가 다른 이력은 상세 정보를 함께 표시
- 실수로 생성한 작업 이력 취소 처리
- 취소된 작업 이력 기본 목록 숨김

운영 원칙:

- 작업 이력은 가능하면 삭제하지 않는다.
- 작업 등록과 작업 기록 결과 입력에서 사용자가 대상·입력값을 변경한 뒤에는 배경 클릭으로 닫지 않으며, 닫기·취소 시 작성 내용 초기화 확인을 한 번 더 받는다. 작업 유형·등록 방법 선택만으로는 작성중 상태가 되지 않는다.
- 잘못 입력한 경우 취소 상태와 취소 사유를 남기는 방향을 우선한다.
- 동 전체 농약 작업은 저장 시 실제 난 묶음 대상과 위치 스냅샷을 생성한다.
- 농약 작업 대상은 동 전체·자동 그룹·사용자 그룹·직접 다중 선택에서 고를 수 있다.
- 직접 다중 선택은 농장 전체 다이 카드를 좌우로 이동하며 다이·구역·난 묶음 단위로 선택하고, 각 구역은 실제 칸 수와 빈 칸을 함께 표시한다.
- 그룹 선택 후 실제 대상 미리보기에서 개별 난 묶음을 제외하고 저장할 수 있다.
- 여러 날 이어지는 작업은 하나의 작업으로 시작·일시중지·재개한다.
- 대상 난 묶음별 시작·완료·건너뛰기와 전체 진행률을 관리한다.
- 완료된 상위 작업은 각 대상 난 묶음 이력에서 전파 출처와 함께 조회한다.
- 난 묶음 이동 후에도 작업 당시 위치와 현재 위치를 구분해 표시한다.
- 다중 생성 작업으로 여러 위치의 난 묶음을 한 번에 생성하고 사용자 그룹 소속과 원인 작업을 함께 남긴다.
- 다중 생성 취소 전 다른 작업·이동·판매·입고 연결을 검사하고, 연결이 없으면 생성 결과와 사용자 그룹 소속을 안전하게 취소한다.
- 난 묶음 상세에서 구조 변경 실행 회차별 원본·결과·총 투입·총 결과·손실과 관계를 만든 작업을 조회한다. 유효한 단일 원본 및 기존 직접 계보는 호환 표시한다.
- 다중 생성 등 작업 효과로 생성된 난 묶음에서도 원인 작업을 통합 이력으로 조회한다.
- 부분·전체 분갈이에서 투입 수량과 손실을 검증하고 여러 결과 난 묶음, 선택한 사용자 그룹 상속, 원본·결과 계보를 함께 기록한다.
- 난 묶음 목록에서 원본을 선택해 분갈이 화면을 열고, 결과별 위치·수량·화분·년생과 손실 사유를 입력하며 수량 일치와 원본 잔여량을 즉시 확인한다.
- 완료된 구조 변경 작업에 별도 보정 작업과 사유를 연결하고, 원본 결과를 삭제하지 않은 채 어떤 작업이 보정했는지 조회한다.
- 원본 구조 변경 작업의 작업일과 해당 작업이 만든 결과의 수량·상태를 보정하고 전후 값을 남기며, 후속 작업·이동·판매·입고 연결이 있는 결과의 수량·상태 변경은 차단한다.
- 월간 기간 작업 캘린더에서 상태를 필터링하고 저장된 작업에 다시 진입해 전체·대상별 진행 상태를 관리한다.
- 기간 작업의 실행 회차·대상 완료·전체 완료 시 실제 완료일을 입력한다. 기본값은 농장 기준 오늘이며 과거 날짜로 수정할 수 있다.
- 기존 작업 기록 입력 화면과 난 묶음 빠른 작업은 신규 작업 실행 API로 즉시 완료 기록을 생성한다.
- 난 묶음 통합 이력에서 구조 변경 결과의 보정 화면을 열어 작업일·수량·상태와 사유를 입력하고 전후 이력을 확인한다.
- 작업 관리는 단일 `통합 관리` 탭에서 미완료 작업과 오늘 변경된 작업을 묶은 `작업 현황`, 상태와 관계없는 `전체 작업` 범위를 제공하고 각 범위를 목록 또는 월간 캘린더로 전환한다. 범위, 보기 방식, 검색·상태·기간·페이지 조건과 캘린더 표시 월은 URL에 유지하며 목록과 캘린더에서 선택한 작업의 같은 상세·실행 화면을 사용한다.
- 작업 상세는 `개요 / 실행 / 대상` 탭으로 구분한다. 개요는 공통·유형별 작업 정보와 대상 수·계획 수량·진행률을 요약하고, 실행은 구조 변경 실행 회차 또는 일반 작업의 대상별·전체 완료 시각과 보정 이력을 표시한다. 대상은 대상 선택 방식과 작업 당시 확정된 난 묶음·입고 대상, 위치·수량·진행 상태를 표시한다.
- 목록은 기간·상태·키워드 조건으로 서버 페이지를 조회하고, 월간 캘린더는 선택한 범위와 월의 모든 서버 페이지를 합쳐 표시한다.
- 작업 등록은 작업 유형을 먼저 고른 뒤 작업 기록 또는 작업 계획 방식을 선택하며, 모든 작업 유형의 기본 등록 방법은 작업 기록이다.
- 자리 이동 작업 기록·계획은 선택 대상을 품종별 독립 작업으로 나누고, 같은 품종의 원본 투입 수량을 실행 회차에서 합친 뒤 복수 이동 결과로 나눈다. 투입 수량보다 적게 이동한 차이가 있으면 완료 전에 자동 계산된 폐기 수량과 별도 폐기 작업 생성을 확인받고, 승인 후 같은 트랜잭션에서 생성한다.
- 난 묶음 관리에서 단일 또는 다중 선택의 `자리 이동`을 누르면 선택한 난 묶음을 고정 대상으로 하고 `자리 이동`·`작업 기록`이 선택된 작업 등록 모달을 연다.
- 분갈이·분주·합식 작업 기록은 진행 회차 없이 선택한 원본을 품종별로 묶는다. 공통 작업 정보에서는 별도 작업 수량을 받지 않고, 결과 입력 footer에서 품종 버튼으로 자유롭게 이동하고 입력 완료 품종을 체크 표시하며, 모든 품종 완료 후 전체 기록을 저장한다.
- 여러 품종의 구조 변경 작업을 함께 기록할 때 배치 선택기는 현재 품종 원본, 같은 품종의 다른 결과, 다른 품종 원본, 다른 품종 결과를 서로 다른 색으로 표시하고 해당 칸의 중복 선택을 막는다. 자동 추론된 결과 위치는 사용자가 배치 선택기에서 확정하기 전까지 결과 배치로 간주하지 않는다. 다른 품종에서 위치를 확정한 결과 행은 즉시 `다른 품종 결과`로 표시하고, 아직 위치를 확정하지 않은 결과에 연결된 원본은 `다른 품종 원본`으로 함께 표시한다. 한 원본에 연결된 모든 결과 위치가 확정되면 그 원본은 점유 계산에서만 제외하고 현재 품종 원본을 뜻하는 노란색 강조에는 포함하지 않는다. 비워진 자리는 다른 품종의 결과 위치로 선택할 수 있다. 이 판단에는 품종별 입력 완료 상태를 사용하지 않는다. 배치 선택기의 이전·다음 버튼은 인접 동의 첫 다이로 이동한다.
- 폐기는 모든 대상의 폐기 결과를 함께 입력한다. 포트 작업 기록도 품종 버튼으로 결과 입력 대상을 이동하고 모든 입고 기록의 결과 입력을 완료한 뒤 전체 기록을 저장한다. 포트 작업 결과의 화분 크기와 시작 년생은 전체 결과에 공통 적용한 뒤 결과별로 수정할 수 있다.
- 기간 작업은 일반 기록형 작업과 자리 이동·분갈이·분주·합식·입고 포트 작업을 함께 계획한다. 구조 변경은 그룹 대상을 실제 난 묶음으로 확정하고 여러 실행 회차에서 일부 수량과 복수 결과를 관리한다.
- 구조 변경 실행 입력은 계획 잔여 수량, 원본 속성, 현재 배치를 기본값으로 추론한다. 분갈이·분주·합식 작업 기록은 원본 전체 수량으로 고정하고, 기간 작업의 실행 회차에서는 현재 수량과 계획 잔여 수량 이내로 작업 수량을 수정할 수 있다. 분주는 결과 수량 합계가 원본 투입 수량보다 커질 수 있다. 사용자는 제외 대상·결과 분리·분주 후보 같은 예외도 수정한다.
- 구조 변경의 손실 수량과 사유는 입력받지 않고, 저장 시 최종 결과 수량을 기준으로 자동 계산해 이력에 남긴다.

## 5. 판매 관리

거래처와 판매 전표를 관리한다.
판매·경매·정산·입금의 상태와 보존 정책은
[`features/sales-auction-settlement.md`](features/sales-auction-settlement.md)를 따른다.

주요 기능:

- 거래처 등록/조회
- 판매 전표 생성
- 판매 전표 취소
- 판매 품목 입력
- 판매 품목별 난 묶음 다중 배분
- 품목 금액과 전표 총액 자동 계산
- 판매 전표 목록/상세 조회
- 판매 전표 상세의 모달 미리보기에서 A5 전표 출력
- 입금 확인

전표 저장 시 난 묶음 예약 수량을 반영한다. 실제 수량 차감은 출고 완료 시 처리한다.
전표 취소 시에는 예약 또는 출고 차감을 역처리한다.

## 6. 경매 추적

경매장 출하 물량을 lot 단위로 추적한다.

주요 기능:

- 경매 lot 조회
- 경매 상태 변경
- 유찰/재경매 대기/반환 확인
- 수량 보정
- 경매 결과 행 관리
- 경매장별 정산 생성
- 정산 재계산
- 정산 목록 서버 페이지 조회, 전체 금액 합계, URL 기반 페이지·상세 선택 복원

핵심은 행 합계가 아니라 **출하 lot별 상태 추적**이다.

## 7. 입금·정산

거래처별 돈 흐름을 관리한다.

주요 기능:

- 판매 전표 입금 확인
- 경매 정산 입금 확인
- 부분입금 처리
- 거래처 잔액 요약
- 입금 이력 서버 페이지 조회와 조회 실패 시 재시도
- 거래처별 정산 설정

## 8. 품종/입고/자재 관리

품종 기준 정보와 입고 흐름, 자재 기준 정보를 함께 관리한다.

주요 기능:

- 품종 등록/수정/비활성화/삭제
- 품종별 난 묶음 표시 색상 지정(미지정 가능)
- 품종 중복 방지는 속과 품종명 조합을 기준으로 처리
- 품종별 연결 난 묶음 조회
- 입고 등록
- 입고 상세 수정
- 유리병 모종 포트 작업 등록
- 입고 취소
- 취소된 입고 삭제
- 자재 등록/수정/비활성화/삭제
- 품종/자재/입고 목록 서버 페이지네이션

운영 원칙:

- 품종과 자재는 삭제보다 비활성화를 우선한다.
- 품종 삭제는 연결 난 묶음, 입고 기록이 없을 때만 허용한다.
- 자재 삭제는 연결 데이터가 없을 때만 허용한다.
- 입고 기록은 난 묶음 생성 전까지만 취소 가능하다.
- 취소된 입고는 삭제 가능하고, 자동 생성된 입고 작업 이력은 함께 정리한다.
- 유리병 모종과 즉시 배치 입고는 입력 필드와 후속 흐름이 다르다.

## 9. 분석

농장 운영 데이터를 바탕으로 판단을 돕는 화면이다.

현재 제공:

- 완료된 판매 전표 기준 월별 매출·출하 추이
- 품종별 매출과 실제 판매 가능 수량
- 거래처별 매출·미입금
- 동·논리 구역 사용 현황
- 작업 유형별 실행 건수와 최근 작업
- 최대 2년 기간 조회

확장 후보:

- 구역 단위 작업 누락
- 상태 이상 추이
- 경매장별 유찰률·반환률·평균 단가

집계 원칙:

- `작성중`, `취소` 판매 전표는 매출·출하·미입금 집계에서 제외한다.
- 판매 분석 기간은 판매일, 작업 분석 기간은 작업 예정일을 기준으로 한다.
- 판매 가능 수량은 주의·이상·병해충·종료·폐기·판매 완료·생성 취소 상태를 제외한 난 묶음의 `quantity - reservedQuantity` 합계다.
- 화면에 근거 없는 추정치나 고정 증감률을 표시하지 않는다.

## 10. 변경 감사 수집

- 난 묶음 단건 생성·보정·이동·삭제 시 변경 전후의 업무 스냅샷과 실제 변경 필드를 저장한다.
- 단건 보정에서 활성 상태가 `종료`, `폐기`, `판매 완료`, `생성 취소`로 바뀌면 `DEACTIVATED`로 구분한다.
- 품종 생성·수정·비활성화·삭제도 별도 품종 스냅샷으로 감사한다.
- 작업 이력과 중복되지 않는 입고 메타데이터 수정·취소·삭제를 감사한다.
- 사용자 난 묶음 그룹의 생성·수정·보관과 실제 구성원 추가·해제를 감사한다.
- 논리 구역 배치 수용량 프로필 변경을 위치 맥락과 함께 감사한다.
- 판매 전표 직접 수정과 상태 변경·취소를 품목 및 난 묶음 배분 스냅샷과 함께 감사한다.
- 거래처 정산 설정 변경과 판매·경매 수동 입금 처리를 감사한다.
- 입금 감사 스냅샷에는 입금자명과 메모를 중복 저장하지 않는다.
- 거래처 생성·수정 시 이름·유형·활성 상태를 감사하고 개인정보 필드는 값 없이 변경 여부만 저장한다.
- 동일 값 보정은 감사 이벤트를 만들지 않는다.
- 조회 화면은 이번 범위에 포함하지 않으며 운영 분석은 `audit_events`와 `scripts/data-audit/audit-event-analysis.sql`을 사용한다.
